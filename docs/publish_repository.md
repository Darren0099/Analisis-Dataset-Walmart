# Mengambil dan memperbarui proyek

Repository: https://github.com/Darren0099/Analisis-Dataset-Walmart

```bash
git clone https://github.com/Darren0099/Analisis-Dataset-Walmart.git
cd Analisis-Dataset-Walmart
pip install -r requirements.txt
```

Buka notebooks/01_walmart_sales_analysis.ipynb melalui Jupyter atau VS Code, atau gunakan tautan Colab pada README. CSV mentah diambil oleh notebook.

Setelah mengubah notebook atau dokumentasi, periksa git diff lalu buat commit dan push ke branch kerja sendiri. Jangan menyimpan token, kredensial, atau file .env. Tautan Google mengikuti izin pemilik dan tidak otomatis terbuka untuk publik.
